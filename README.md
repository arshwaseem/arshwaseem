## About Me

I'm a backend-leaning **full-stack engineer** — most comfortable designing a Spring Boot service and
the schema underneath it, but just as at home in **React, Next.js, TypeScript and JavaScript**
building the interface on top. Recent work has ranged from tuning JVM performance on
high-throughput security microservices to single-handedly rewriting a legacy PHP system into a
modern Next.js application — HTML/CSS, auth, database cleanup and all.

I care about **observability** (if I can't see it, I don't trust it), clean data models, and code
that survives contact with production.
